          • 订阅节点导入教程

          本教程指导用户如何将订阅节点导入到：

          • Windows：Clash Verge

          • Android（安卓手机）：Clash Meta for Android

          • iOS（iPhone/iPad）：Shadowrocket

          请根据自身设备型号，跳转到对应的导入方法。

          请逐字阅读，避免遗漏导致步骤错误！步骤一旦出错，可能导致恢复原状十分困难！

          Clash Verge

          在 Windows 电脑上下载并安装 Clash Verge 后：

          1. 打开 Clash Verge，点击左侧的“订阅”按钮。

          2. 在“链接”栏中输入订阅链接，点击“导入”按钮。 

            xxxxxxxxxx
            1
            1
            https://img.beyondwj.cc/proxy/BNFDH.yaml

            新出现了一个订阅节点“BNFDH”，右键选择使用。

          3. 在“代理”中的“PROXY”组中选择“hysteria 2”，在“节点选择”组中选择“JP-HOUSE”。

            这样可以做到：访问节点时，先通过 hysteria 协议连接到日本数据中心节点，再二次中转到日本住宅节点，保证访问速度和稳定性。该原理后续不再赘述。

            注意：如果 hysteria 2 节点速度过慢甚至无法连接，但此时若其他协议（最好是 h2-reality，该协议抗封锁较强）可以正常连接，可临时切换到该协议。在 hysteria 2 节点恢复访问后，强烈建议第一时间切换回来。

          4. 首页“系统代理”开关打开，即可正常访问网络。

          5. 事后的更新：如果订阅节点更新了，右键点击“BNFDH”订阅节点，选择“更新”，即可自动更新，不需要任何手动操作。

          Clash Meta for Android

          在 Android 手机上下载并安装 Clash Meta for Android 后：

          1. 打开 Clash Meta for Android，点击“配置”按钮。依次选择：右上角“+”、URL。
            名称输入“BNFDH”，URL栏中输入订阅链接：

            xxxxxxxxxx
            1
            1
            https://img.beyondwj.cc/proxy/BNFDH.yaml

            点击右上角“保存”按钮。此时配置表中应当多出一个名为“BNFDH”的配置文件。

          2. 将其选中。回退到主页，将“已停止”切换为“运行中”。点击“代理”，进入代理界面，选择“PROXY”组中的“hysteria 2”，在“节点选择”组中选择“JP-HOUSE”；右下角闪电图标可以一键测速。

            注意：如果 hysteria 2 节点速度过慢甚至无法连接，但此时若其他协议（最好是 h2-reality，该协议抗封锁较强）可以正常连接，可临时切换到该协议。在 hysteria 2 节点恢复访问后，强烈建议第一时间切换回来。

          3. （如果做过可以忽略）在停止运行的状态下，点击设置、网络，最下部有两个选项：

            • 访问控制模式：选“不允许已选择的应用”。

            • 访问控制包列表：把你不想走节点的国内应用（特别是微信、QQ等）打勾。请务必仔细勾选，绝不可把微信等国内应用漏掉！

            当然，你也可以选择“允许已选择的应用”，然后只勾选你想走节点的应用，这样也可以达到同样效果。

          4. 事后的更新：如果订阅节点更新了，点击“配置”，选择该配置，点击右边的三个点，选择“更新”，即可自动更新，不需要任何手动操作。

          Shadowrocket

          在 iPhone 或 iPad 上下载并安装 Shadowrocket（需要日版或其他非中国区 Apple ID）后：

          1. 打开 Shadowrocket，在首页，点击右上角“+”：
            备注输入“BNFD”，URL栏中输入订阅链接：

            xxxxxxxxxx
            1
            1
            https://img.beyondwj.cc/proxy/BNFDH-SR.yaml

            点击右上角“保存”按钮。由于后续步骤需要精确匹配该备注，上述备注输入绝不能错！

            以上操作后，应该可以看到首页出现了“BNFD”节点组。你已经可以选择其中的某一个。这是数据中心节点（机房节点），下一步导入住宅节点。

          2. 转到配置，依然点击右上角“+”，直接输入以下URL：

            xxxxxxxxxx
            1
            1
            https://img.beyondwj.cc/proxy/BNFDH-SR.conf

            点击“下载”按钮。
            以上操作后，可以看到配置出现了“BNFDH-SR”新配置。长按，选择“使用配置”，然后回到首页，点击“BNFDH-SR”节点组的“JPHOUSE”节点即可。

          3. 在首页往上拉，会拉到“代理分组”的页面。点击“机房节点”，选择“hysteria 2”，其他的默认配置已是最优，可以返回。

          4. “全局路由”选择“配置”，根据配置文件的规则转发流量。

          5. 事后的更新：如果订阅节点更新了，点击“配置”，长按该配置，选择“更新”，即可自动更新，不需要任何手动操作。
